# Airbrush Time - Contacto y Blog

Este es un sitio web simple con un formulario de contacto y un blog sobre aerografía. 

## Características:
✅ Blog con artículos recientes.  
✅ Formulario de contacto con validación en JavaScript.  
✅ Diseño moderno y responsivo.  
✅ Estilos con efecto neón en el botón de envío.

## Cómo usar
1. Sube los archivos a GitHub.
2. Activa **GitHub Pages** en la configuración del repositorio.
3. Visita tu sitio en `https://airbrushtime.github.io/web/`
